# Troubleshooting

Symptom → likely cause → fix. When a print goes wrong, start here.

## Planned / contents

- Stringing / oozing
- Warping / bed adhesion
- Clogs / under-extrusion
- Layer shifting
- Poor overhangs / bridging
- Rough or pockmarked surfaces (often [wet filament](../reference/filament-drying.md))

> Many quality issues are actually calibration or material problems — cross-link to
> [Calibration](../calibration/) and [Materials](../materials/) rather than duplicating.
