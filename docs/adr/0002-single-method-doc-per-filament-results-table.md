# One method document plus a per-filament results table

The calibration procedure is identical for every filament — only the numbers and photos
change. Rather than duplicating the whole procedure per material (one file per filament),
we write the step-by-step method **once** and record each spool's measured values as **one row
in a results table** at the bottom of the guide. Adding a new material (PLA, ABS, …) means
appending a row, not copy-pasting the method. Trade-off: material-specific quirks that
don't fit a table cell go in the row's "Notes" or, if large, a future dedicated section.
